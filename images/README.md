# Article charts

These three PNG files are the chart set supplied alongside the authoritative revised research pack. They are article illustrations and are not generated by `run_experiment.py`.

- `chart_1_cl_inventory.png`: simplified CL inventory as ETH price changes. Chart inputs: Pₐ = 1,500 and Pᵦ = 2,500 USDC per ETH; L = 1,000 arbitrary liquidity units.
- `chart_2_delta_hedge.png`: LP local delta and the first-order linear-perpetual hedge target, using the same chart inputs as Figure 1.
- `chart_3_hedging_cost_components.png`: hypothetical accounting components (12 USDC trading-fee income, 7 USDC spread/slippage cost, 6 USDC net funding cost). These values are illustrative only.

**Important distinction:** the chart inputs are not the simulation configuration. The synthetic experiment in `src/clhedge/simulation.py` uses its own configuration (initial price 2,000; range 1,800–2,200; 10,000 USDC initial LP value). Do not combine the chart values and simulation outputs as if they came from one experiment. No ±5% experiment is part of this package.

All three charts exclude fees and protocol-specific accounting unless stated. Chart 3 is not a historical observation, a backtest result, or a forecast.
